# A scanned site keeps what the user opens

The first Scan of a site turns Lens on there. On a site with kept lists that the user allowed, the panel scans each page the tab shows, with no click: when the tab comes to the front, when it loads, and when the page draws new content over the marks, such as a tab click. Each such Scan marks the players and keeps the page's lists like any Scan: a new list is added, and a list read again replaces the kept one (ADR-0004). The Lineup shows the lists kept for the page's site and week. On other pages, such as Sleeper, the panel keeps the last Lineup. "Forget {site}" removes every list of the site and its marks, and Lens then waits for a Scan there again. A page that draws its table after it loads is watched for 10 seconds for the players.

## Why

Users think of a rankings site, not of Scans: Fantasy Footballers has one page per position and Yahoo one tab per position, and once the user scanned one, they expect the others to count as they open them. A first version only marked the players on those pages and kept no ranks until a click on "Scan page", with "Ranks out of date" when a kept list changed. The two kinds of reading were hard to follow. The problem of ADR-0009, lists that changed with no click, came from Scans on any change of the page, ads included. Here a Scan runs only for a page or tab the user opened, and lists in another Scoring Format still stay out of the Lineup. Removing one list does not fit, as the list comes back when its tab opens again; a FLEX list already ranks the RB, WR and TE Slots, so position lists need no removal. After a reload Chrome lets a script in only with site access, so with a toolbar click alone the page waits for the next click. Yahoo can serve a first page with older ranks than its tabs load; the Lineup then follows what the page shows.
