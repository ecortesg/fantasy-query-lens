# A Slot is a set of positions

A Slot is defined only by the positions it accepts. QB is {QB}, FLEX is {RB, WR, TE}, SUPER_FLEX is {QB, RB, WR, TE}. The Lineup fills each Slot from one Ranked List: a cross-position list when it covers every position the Slot accepts, or the positional list when the Slot has one position. A list that ranks none of the players left for a Slot passes the Slot to the next list that covers it: a short list, such as a 4-row preview of a paid FLEX list, is the top of the full list, so the players it does rank are right, and the rest come from the other lists. When no list covers a Slot but position lists cover each of its positions, the player with the best rank in his own position list starts, and the panel says "by WR rank" beside him.

## Why

One rule then serves every flex type Sleeper has, with no special cases for Superflex. A list that covers RB, WR and TE together fills FLEX for sure. Without one, FLEX is a guess: WR #18 and RB #18 are not worth the same. Sites such as Fantasy Footballers have a FLEX list only for paying users, so an empty FLEX helped no one, and the note shows the guess. When a cross-position list exists it ranks everything it covers, because comparing across positions is the thing the ranker did on purpose.
