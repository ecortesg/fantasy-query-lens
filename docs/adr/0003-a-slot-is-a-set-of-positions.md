# A Slot is a set of positions

A Slot is defined only by the positions it accepts. QB is {QB}, FLEX is {RB, WR, TE}, SUPER_FLEX is {QB, RB, WR, TE}. The Lineup fills each Slot from one Ranked List: a cross-position list when it covers every position the Slot accepts, or the positional list when the Slot has one position. A list that ranks none of the players left for a Slot passes the Slot to the next list that covers it: a short list, such as a 4-row preview of a paid FLEX list, is the top of the full list, so the players it does rank are right, and the rest come from the other lists.

## Why

One rule then serves every flex type Sleeper has, with no special cases for Superflex. It also answers "can this page fill FLEX?": only when a list covers RB, WR and TE together. A page that ranks one position gives the order for that position and says it cannot fill FLEX. When a cross-position list exists it ranks everything it covers, because comparing across positions is the thing the ranker did on purpose.
